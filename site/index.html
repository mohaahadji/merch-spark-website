A FEW GOOD QUESTIONS

Before you dive in.

Is Spark an Amazon product?+

No. Merch Spark is an independent software project. It is not affiliated with, sponsored by, or endorsed by Amazon.

Can I download Spark here?+

Not yet. This website introduces the project and its data practices. Spark is in active development; contact the creator for current availability. There is no public installation or account sign-up flow on this website.

Is Amazon Ads reporting available?+

Amazon Ads access is pending. Spark has a reporting integration implementation that requires an approved Ads API client, an authorized advertiser profile, and a valid access token. It is not a ready-to-connect public Ads service.

Are the numbers in the preview real?+

No. The website’s dashboard illustration uses sample data. The extension’s reporting features use data retrieved from your connected Amazon session; missing or incomplete data is marked as such.

Who’s behind the project?+

Spark is an independent project from the creator behind Merch AI, offered under the Mercher World project name. See the About page or contact the creator for more information.
